## 1. 阻断发现（3 条）

### 阻断 1：「paginated 墙」漏记——既有桌面对话在当前已验证栈上很可能不可恢复，两报告均未记录，方案 §8.3 明令该记的记没记

我重算的事实链：

- 兼容报告自己的证据 `evidence/m1/as-list-default.json`：**全部 14 条既有桌面对话**（含「评估 Railway 跨设备 Codex 对话」等真实工作对话）`historyMode="paginated"`、`cliVersion="0.153.4"`（本人解析该文件逐条核对）；唯一 `legacy` 线程是探针自建的。
- 官方文档（https://learn.chatgpt.com/docs/app-server.md，本人重取，逐字）："Paginated thread creation isn't supported yet and returns JSON-RPC error `-32601`. App-server can list and read summaries for existing paginated records, but **full-history reads, turn pagination, and resume fail closed** until paginated history is supported."——resume 与全史读取对 paginated 线程**fail closed**。
- 平台报告 L7（第 177 行）已抄录该文档规则，但只当作文档事实；兼容报告全文**未出现 paginated 与既有线程的任何关联**。两份并行报告各持半边，谁都没合成。
- 后果：产品核心目标「接入既有指定桌面对话」（方案 §2.1、§3.3）在 M1 已验证的栈（PATH `codex app-server` 0.149.0、探针只建过 legacy 线程、从未 resume 过任何既有线程）上，按官方文档**预期直接失败**；桥接当前唯一已验证路径是自建 legacy 线程。这正是方案 §8.3（第 202 行）"若桌面线程格式无法由官方接口安全处理，应明确记录『不支持当前版本接入』，而不是编辑会话数据库。使用新建桥接专用对话只可作为单独验证路径，不能冒充原有桌面对话兼容性通过"所要求的记录——两报告都没有做。
- 对 go 结论的影响：「有条件 go」的条件清单缺了这条**决定性条件**；且按 §8.3，自建对话验证不得冒充桌面对话兼容性通过——现有报告的写法恰好踩在这条红线的边上。

### 阻断 2：版本错配——环境清单把两个不同版本的二进制混为一谈，全部实测结论的载体（0.149.0）≠ 桌面后端实际版本（0.153.4）

我重算的事实链：

- 直接运行桌面后端二进制：`& 'C:\Users\Administrator\AppData\Local\OpenAI\Codex\bin\8e5b6932251c2c1c\codex.exe' --version` → **`codex-cli 0.153.4`**；而 PATH `codex --version` → `codex-cli 0.149.0`（npm wrapper 经 `findCodexExecutable()` 解析到 node_modules 平台包自带二进制，不读 `CODEX_CLI_PATH`）。
- `env-recon.txt` 第 30 行：桌面后端 PID 25076 的可执行路径就是上述 8e5b 二进制 ⇒ **桌面后端是 0.153.4**；既有线程的 `cliVersion="0.153.4"` 互证。探针连接的 app-server 是 0.149.0（`userAgent` 佐证）。
- 兼容报告 §2 第 38 行却写："实际二进制 | `C:\...\bin\8e5b6932251c2c1c\codex.exe`（约 295 MB；`config.toml` 的 `CODEX_CLI_PATH` 指向它）"——挂在「CLI 版本 codex-cli 0.149.0」行下，事实错误：该二进制不是 PATH CLI 的二进制，而是桌面后端的 0.153.4。
- 后果：① 环境清单存在事实错误（判据①「每个断言附命令原文与输出」在此断言上不成立——报告从未对该二进制跑过 `--version`）；② 「桌面与桥接共用同一存储」的兼容结论是在**跨版本（0.149.0 写入端 ↔ 0.153.4 数据）**场景下未验证版本一致性；③ M2 若照报告实现（spawn PATH `codex app-server`=0.149.0），叠加阻断 1，桥接对既有 paginated 线程的 resume/read 预期撞墙；若改用桌面 0.153.4 二进制，则 M1 的全部接口实测结论需要在新版本上重验——两报告对此均无一字。

### 阻断 3：「桌面可见性」被静默丢弃——方案明令的验证项既未做、也未列入未验证表，go 依据中用推断充当代证

我重算的事实链：
